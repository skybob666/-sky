# 内容来源记录（初版占位）

当前版本使用的是交互与信息架构示例，不应作为正式科学资料提交。

| 内容对象 | 当前处理 | 正式版需要补充 |
|---|---|---|
| 雅诗兰黛品牌与产品 | 课堂示例，不代表官方资料 | 老师允许使用的品牌资料、产品图与授权范围 |
| 红景天、千日菊、三叶鬼针草 | 植物卡占位 | 老师指定或可核验的植物资料、拉丁学名、提取部位 |
| 泛醇、透明质酸钠等成分 | 用于演示成分解码交互 | 成分命名、功能分类、来源与访问日期 |
| 研究证据 | 页面只写“待核验” | 证据类型、证据等级、原始资料链接 |
| 线稿插图 | 页面内自制 SVG 线稿 | 在原创声明中注明自制，并保留源代码 |

## 内容纪律

- 不把植物研究结果直接写成整款产品功效。
- 不写医疗、治疗、修复等表述。
- 未经老师确认，不把示例配方称为雅诗兰黛官方配方。
- 每条正式成分说明都记录来源、访问日期和证据等级。
