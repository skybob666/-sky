# 老师资料到位后的替换清单

## 必须向老师确认

- [ ] Logo 文件和允许使用范围
- [ ] 正式品牌名称、产品名称和产品图片
- [ ] 参考配方或可公开展示的成分信息
- [ ] 植物草本科普的指定资料或推荐来源
- [ ] 是否允许课程内部使用品牌示例，是否允许公网部署
- [ ] 提交平台、截止时间、文件命名与格式
- [ ] AI 使用声明和原创声明是否有固定模板

## 网站中需要替换的位置

- [ ] `index.html` 的标题、品牌示例说明和产品文案
- [ ] `data.js` 中的成分中文名、英文名、序位和配方角色
- [ ] `data.js` 中的植物拉丁学名、科属、提取部位和来源
- [ ] 来源板块的“待核验”状态、资料链接与访问日期
- [ ] 页脚的作品声明、部署范围和个人/小组署名
- [ ] `styles.css` 中的视觉色值（如果老师提供官方规范）
