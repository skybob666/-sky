# 技术栈说明（初版）

- 页面结构：HTML5 语义化标签与锚点导航。
- 页面样式：原生 CSS，使用 CSS 变量管理颜色、间距和字体。
- 交互逻辑：原生 JavaScript，负责数据渲染、筛选、详情面板、键盘关闭和 URL hash 状态。
- 数据组织：`data.js` 中的单一数据对象，后续可替换为 JSON 文件。
- 部署方向：静态托管。正式公开部署前，需先确认课程和品牌使用边界。
- 源文件：当前目录中的 `index.html`、`styles.css`、`data.js`、`app.js` 即可编辑源文件。

## 初版设计取舍

本版不引入 React、数据库、账号系统或复杂路由，以便在每周投入较少的情况下优先保证页面可访问、导航清晰、移动端可用和内容边界清楚。
