# 草肤荟·成分探索馆｜初版网站

这是一个**课程设计初版**，以雅诗兰黛作为示例品牌，用于先验证网站结构、视觉方向和核心交互。

> 重要：当前内容不是雅诗兰黛或草肤荟官方资料，不代表真实品牌配方、产品功效或商业宣传。

## 如何预览

直接双击 `index.html` 即可预览。若需要更接近部署环境的本地预览，可双击 `启动本地预览.ps1`，或在此目录执行：

```powershell
py -m http.server 8000
```

然后打开 <http://localhost:8000>。

## GitHub Pages 部署

本目录已经包含 `.github/workflows/pages.yml`。把本目录中的文件放到 GitHub 仓库根目录并推送到 `main` 分支后，GitHub Actions 会自动部署。

部署成功后，网址通常是：

```text
https://skybob666.github.io/-sky/
```

如果第一次部署没有自动开始，请在 GitHub 仓库的 **Settings → Pages** 中确认 Source 使用 **GitHub Actions**，然后到 **Actions** 页面手动运行工作流。

## 本版已完成

- 单页长滚动结构与锚点导航
- 产品配方卡（示例）
- 8 项示例成分序位带
- 3 张植物图鉴卡
- 成分筛选：全部 / 植物提取物 / 保湿类 / 其他
- 植物与成分共享详情面板
- URL hash 直达成分详情，例如 `#ingredient=panthenol`
- 桌面端弹窗与移动端底部抽屉
- 方法与来源、课程作品声明、非官方声明
- `noindex,nofollow`，适合课程内部演示

## 下一步替换顺序

1. 用老师确认的品牌 Logo、产品名称、产品图片或配方卡替换示例内容。
2. 在 `data.js` 中逐项核对成分名称、序位、植物关联和资料来源。
3. 替换 `index.html` 中的“雅诗兰黛示例”文案与课程声明。
4. 补齐 `docs/` 下的来源记录、AI 使用声明、原创声明和测试记录。
5. 取得老师同意后再决定是否公开部署。

## 文件说明

- `index.html`：页面结构与文案
- `styles.css`：视觉规范、响应式和移动端样式
- `data.js`：植物与成分数据
- `app.js`：渲染、筛选、详情面板、hash 状态和导航高亮
- `docs/`：后续交付与过程记录模板
